# CS 370 – Current and Emerging Trends in Computer Science

## Project Two: Pirate Intelligent Agent

For this project, I worked on creating an intelligent pirate agent that could navigate through a maze to find treasure. The goal was to use deep Q-learning and neural networks to train the pirate to make decisions and find a path to the treasure without having to tell it exactly which direction to move every time.

I was provided with starter code that included the maze environment, the experience replay class, and some of the functions needed to run the game. My main responsibility was to complete the training portion of the project using deep Q-learning. I worked on how the agent selected actions, learned from rewards, stored previous experiences, and improved its decisions over time. I also worked with the exploration rate and training settings to help the agent learn how to navigate the maze.

This project helped me better understand how artificial intelligence works beyond just reading about it. I was able to see how a neural network could be used to make decisions and how reinforcement learning allows an agent to improve through trial and error.

## What Do Computer Scientists Do and Why Does It Matter?

Computer scientists use technology, programming, and problem-solving skills to develop solutions to different problems. Their work can involve creating software, improving existing systems, developing artificial intelligence, and finding ways to make technology more useful.

I think computer science is important because technology is involved in almost everything we do today. From healthcare and banking to transportation and entertainment, computer scientists help develop the systems that people depend on every day. This course showed me how AI can be used to solve problems that would normally require someone to make decisions manually.

## How Do I Approach a Problem as a Computer Scientist?

When approaching a problem, I try to understand what needs to be accomplished before jumping into the code. I like to break larger problems into smaller steps so I can work through them one at a time. Once I have something working, I test it and make changes when something does not work the way I expected.

I used this approach throughout the pirate intelligent agent project. There were times when the training process did not work correctly, and I had to go back through the code to figure out what was causing the problem. I learned that programming is not always about getting everything right the first time. A lot of it involves testing, troubleshooting, and making improvements until the program works as intended.

## What Are My Ethical Responsibilities to the End User and the Organization?

As a computer scientist, I believe one of my biggest responsibilities is making sure the technology I develop is safe, reliable, and used appropriately. Users should be able to trust that the software they are using works correctly and that their information is being protected.

When working with artificial intelligence, I also think it is important to consider how the system makes decisions. AI can make mistakes, and depending on how it is trained, it can produce biased or inaccurate results. Developers need to test their systems and understand the possible consequences before making them available to users.

I also have a responsibility to the organization I work for by writing maintainable code, following security practices, and being honest about any problems or limitations with the software. Overall, this course helped me understand that being a computer scientist involves more than just writing code. It also means thinking about how that code affects the people who use it.
